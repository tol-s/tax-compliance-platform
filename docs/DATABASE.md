# Database and entity map

PostgreSQL 16. All primary keys are UUIDs (time-ordered UUIDv7 generated by
Laravel `HasUuids`). All tenant-owned tables carry `organization_id` (FK,
indexed). Money is `NUMERIC(20,4)`; rates are `NUMERIC(12,8)`. Provider-specific
and rule data is `JSONB`. Timestamps are `timestamptz`.

Legend: **[T]** tenant-owned, **[I]** immutable once written / finalised,
**[A]** append-only, **[G]** global (platform-level configuration).

## Entity map

```
organizations ─┬─ organization_user (membership, role_id) ── users
               ├─ roles [T|G] ── permission_role ── permissions [G]
               ├─ clients [T] ── client_user (assignment)
               │     ├─ taxpayer_profiles [T] (1:1)
               │     ├─ tax_registration_statuses [T][I*] (effective-dated history)
               │     ├─ registration_documents [T] ── documents
               │     ├─ accounting_connections [T]
               │     │     ├─ accounting_sync_runs [T]
               │     │     │     └─ accounting_sync_errors [T]
               │     │     └─ raw_* [T]  (accounts, contacts, invoices, bills,
               │     │                   payments, journal_entries,
               │     │                   bank_transactions, tax_rates)
               │     ├─ canonical ledger [T]
               │     │     accounts, contacts(customers/vendors), tax_rates,
               │     │     journal_entries ── journal_lines,
               │     │     invoices ── invoice_lines, bills ── bill_lines,
               │     │     payments, bank_transactions
               │     │     └─ normalization_logs [T]
               │     ├─ tax_mappings [T] (account → classification, overrides)
               │     └─ tax_periods [T]
               │           ├─ calculation_runs [T][I on FINALIZED]
               │           │     ├─ calculation_results ── calculation_lines
               │           │     ├─ calculation_traces [A]
               │           │     ├─ calculation_adjustments [A]
               │           │     └─ threshold_evaluations
               │           ├─ working_papers [T][I] ── working_paper_rows
               │           ├─ form_instances [T] ── form_values (+ provenance)
               │           │     └─ documents (generated PDFs)
               │           └─ exceptions [T] ── exception_comments
               ├─ audit_logs [T][A]
               ├─ notifications [T]
               └─ saved_filters [T]

Tax configuration [G] (versioned, publish-once):
tax_jurisdictions ── tax_types ── tax_rule_sets ── tax_rule_versions [I on PUBLISHED]
                                         │                └─ tax_rules (DSL JSONB)
                                         ├─ tax_thresholds (effective-dated)
                                         └─ tax_classifications
form_definitions ── form_versions [I on PUBLISHED]
                        ├─ form_sections ── form_fields
                        └─ form_mappings (field → source path JSONB)
rule_test_scenarios ── rule_test_runs
```

`[I*]` Registration status rows are never edited; a change closes the current
row (`effective_to`) and inserts a new one, with a mandatory reason and
supporting document, and an audit event.

## Key tables (abridged columns)

### Tenancy and identity

| Table | Columns |
|-------|---------|
| `organizations` | id, name, slug (unique), country_code, base_currency, settings JSONB, timestamps |
| `users` | id, name, email (unique), password, mfa_secret (encrypted, nullable), mfa_enabled_at, current_organization_id, last_login_at, timestamps |
| `organization_user` | id, organization_id, user_id, role_id, status (ACTIVE/INVITED/SUSPENDED), unique(organization_id, user_id) |
| `permissions` | id, key (unique, e.g. `calculations.approve`), group, description |
| `roles` | id, organization_id (null = system role template), key, name, is_system; unique(organization_id, key) |
| `permission_role` | role_id, permission_id (PK both) |
| `client_user` | client_id, user_id, organization_id (restricts preparers to assigned clients) |
| `personal_access_tokens` | Sanctum; tokens expire, scoped abilities |

### Clients and registration

| Table | Columns |
|-------|---------|
| `clients` | id, organization_id, legal_name, trade_name, taxpayer_identifier (encrypted + blind index for search), entity_type, industry, status, timestamps, soft deletes |
| `taxpayer_profiles` | id, organization_id, client_id (unique), business_address JSONB, registration_information JSONB, registration_date, fiscal_year_end_month, accounting_period, currency, jurisdiction_id, notes |
| `tax_registration_statuses` | id, organization_id, client_id, tax_type_id nullable, **vat_status** (`VAT_REGISTERED` / `NON_VAT`), **status_source** (`BIR_CERTIFICATE` / `USER_ENTERED` / `ADMIN_OVERRIDE`), effective_from, effective_to, source_document_id, last_verified_at, reason, created_by; exclusion constraint preventing overlapping ranges per client |
| `registration_documents` | id, organization_id, client_id, document_id, kind (e.g. `CERTIFICATE_OF_REGISTRATION`), issued_at |
| `documents` | id, organization_id, disk, path, original_name, mime, size, sha256, kind, created_by |

### Accounting

| Table | Columns |
|-------|---------|
| `accounting_connections` | id, organization_id, client_id, provider (`XERO`/`QUICKBOOKS`/`SIMULATOR`), status (`CONNECTED`, `SYNCING`, `SYNCED`, `ERROR`, `DISCONNECTED`, `TOKEN_EXPIRED`), external_tenant_id, external_org_name, access_token (encrypted), refresh_token (encrypted), token_expires_at, scopes, last_synced_at, sync_cursor JSONB |
| `accounting_sync_runs` | id, organization_id, connection_id, status, trigger, started_at, completed_at, counts JSONB (fetched/created/updated/failed per entity), api_calls, correlation_id |
| `accounting_sync_errors` | id, sync_run_id, entity, provider_record_id, code, message, payload_excerpt, retryable, attempts |
| `raw_*` | id, organization_id, connection_id, sync_run_id, provider, provider_record_id, source_payload JSONB, payload_hash, source_updated_at, imported_at; unique(connection_id, provider_record_id, payload_hash) |
| canonical tables | provider-neutral columns + `source_provider`, `source_record_id`, `source_sync_id`, `source_payload_hash`, `raw_record_id` |
| `journal_lines` | id, organization_id, client_id, journal_entry_id, account_id, date, description, debit, credit, currency, tax_code, tax_rate_id, counterparty_id, lineage columns; indexes (client_id, date), (account_id) |
| `normalization_logs` | id, sync_run_id, raw_table, raw_record_id, canonical_table, canonical_id, action, warnings JSONB |

### Tax configuration (global)

| Table | Columns |
|-------|---------|
| `tax_jurisdictions` | id, code (`PH`), name, currency |
| `tax_types` | id, jurisdiction_id, code, name, filing_frequency |
| `tax_rule_sets` | id, tax_type_id, code, name, selector JSONB (e.g. applies when `taxpayer.vat_status == NON_VAT`) |
| `tax_rule_versions` | id, rule_set_id, version (int), status (`DRAFT`/`PUBLISHED`/`RETIRED`), effective_from, effective_to, published_at, published_by, source_reference, checksum; unique(rule_set_id, version) |

## Indexing policy

Every tenant table: `(organization_id)` and the natural access path, e.g.
`(organization_id, client_id)`, `(client_id, tax_period_id)`,
`(connection_id, provider, provider_record_id)`, `(status)`,
`(effective_from, effective_to)`. Hot lists (journal lines, raw records) get
composite indexes on the columns the Data Grid filters by.
